# Student Performance Analytics 📊

## About the Project
Student Performance Analytics is a Python-based data analysis project designed to analyze students' academic performance using NumPy, Pandas, and Matplotlib.

The project processes student marks, calculates performance statistics, identifies top-performing students, and presents insights through data visualization.

## Features
- Calculate total marks of students.
- Calculate average marks.
- Identify highest and lowest scores.
- Assign grades based on performance.
- Check Pass/Fail status.
- Identify Top 3 performers.
- Analyze subject-wise performance.
- Visualize student performance using graphs.

## Technologies Used
- **Python** – Programming language
- **NumPy** – Numerical calculations and array operations
- **Pandas** – Data manipulation and analysis
- **Matplotlib** – Data visualization

## Installation

1. Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Navigate to the project directory:

```bash
cd student-performance-analytics
```

3. Install required libraries:

```bash
pip install numpy pandas matplotlib
```

4. Run the Python file:

```bash
python main.py
```
